# Installation

## Backend Strapi

```shell
cd .\Backend\
npm install
```

## Frontend Vue.js

```shell
cd .\Frontend\
npm install
```

# Developpement

## Backend Strapi

```shell
cd .\Backend\
npm run dev
```

url : http://localhost:1337/admin/auth/login

## Frontend Vue.js

```shell
cd .\Frontend\
npm run dev
```

url : http://localhost:5173/home
